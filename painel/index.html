Painel de edição

Entrar no painel

Este painel edita o site publicado no GitHub. Só quem tem a chave de acesso (token) do repositório consegue salvar alterações. Se você não é o responsável pelo site, não há nada a fazer aqui.

Não sabe como criar a chave? Abra Ajuda e siga o passo a passo. A chave fica só neste navegador e nunca é enviada a ninguém, exceto ao GitHub.

Páginas

    Arquivos

    Menu, cabeçalho e rodapé são compartilhados por todas as páginas e não são editados aqui.

    Clique em um texto para editar. Clique em uma imagem e em Trocar imagem. Para adicionar um item, clique nele, use Duplicar bloco e edite a cópia.

    Materiais para baixar

    Arquivos da pasta materiais/. Para substituir, envie um arquivo com o mesmo nome. Para adicionar, envie um novo e depois, na página Materiais, duplique um cartão e edite o link para materiais/nome-do-arquivo.

    Ajuda

    Como criar a chave de acesso (uma vez)

    1. Entre no GitHub, clique na sua foto e em Settings.
    2. No fim do menu, abra Developer settings > Personal access tokens > Fine-grained tokens e clique em Generate new token.
    3. Dê um nome (por exemplo, "Painel HIDRO") e escolha a validade (90 dias é uma boa escolha).
    4. Em Repository access, escolha Only select repositories e marque só o repositório do site.
    5. Em Permissions > Repository permissions, ponha Contents: Read and write (e deixe o restante como está).
    6. Clique em Generate token e copie o texto que começa com github_pat_. Ele só aparece uma vez.

    Como editar

    • Escolha a página na lista à esquerda e clique nos textos para corrigi-los.
    • Enter dentro de um texto insere uma quebra de linha. Para criar um novo parágrafo ou item, use Duplicar bloco.
    • Para trocar uma imagem: clique nela (aparece um contorno vermelho) e em Trocar imagem.
    • Para mudar o endereço de um botão ou link: clique no texto dele e em Link.
    • Ao terminar, clique em Salvar e publicar. O site atualiza em 1 a 2 minutos.

    Se algo der errado

    Todas as versões ficam guardadas no GitHub (aba Commits do repositório). Dá para voltar a qualquer versão anterior.

    O que o painel não faz

    • Não muda o menu, o cabeçalho e o rodapé (são iguais em todas as páginas).
    • Não cria páginas novas nem muda o layout.
    • Não atualiza os arquivos Word e PDF: eles são arquivos separados (aba Arquivos).
